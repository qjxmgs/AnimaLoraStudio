支持 Anima-2.9B 等不同层数的 Anima 底模 · LoRA 与底模层数兼容检查 · 未打标图片也参与训练

### 新增

- **支持 Anima-2.9B 等不同层数的 Anima 底模（#502、#504）**
  底模层数现在直接从权重文件读取，40 层的 Anima-2.9B 及同类插层扩展版可以正常训练和出图。设置页模型目录新增 Anima-2.9B preview-v1 下载条目（约 5.8 GB）；底模下拉、模型路径选择和设置页主模型卡都会标出「N 层」。
  - 出图的 Block 交换层数和训练的 SRA 层不再按固定层数封顶，超过底模实际层数时按全部换出 / 最后一层处理。
- **LoRA 与底模层数兼容检查（#503、#504）**
  新训练的 LoRA 会记录训练所用底模的层数。出图时层数确定不匹配的 LoRA 会被拒绝，可能不匹配的（如没有记录的旧 LoRA 或外部 LoRA）会弹出提醒；出图页 LoRA 目录每行标出训练底模层数，并用红 / 黄区分不匹配与可能不匹配。
  - 继续训练已有 LoRA 或从恢复点续训时，如果底模层数与原来不同，会在开训前说明原因并停止。

### 变更

- **未打标的图片现在也会参与训练（#599）**
  图片是否参与训练只由训练集的扫描范围决定，没有 Caption 文件的图片不再被排除，而是以空文本训练，同一数据集的样本数和预计步数可能因此增加。打标和标签编辑阶段也不再要求全部图片打完标签才能推进。
  - 标签编辑中清空标签会保存为空 Caption，不删除文件；缺失和空白 Caption 统一显示「未打标」；打标时「已有 caption」选「跳过」也会为它们打标。
- **含无法识别的 DiT 层权重的底模文件现在会在加载时报错（#502）**
  例如带额外 `blocks.*` 键的 ComfyUI `fp8_scaled` 文件：以前会静默加载但训练和出图结果不正确，现在直接提示文件与模型结构不符。

### 修复

- **第三方微调的 Anima 底模加载时报 `pos_embedder.seq` 尺寸不匹配（#502、#601）**
  这类底模现在可以正常加载、训练和出图。
- **自行下载的自定义底模没有出现在训练页和底模下拉中（#504）**
  以前只能在设置页选中用于出图，现在与本地注册的底模一样在各处列出。
- **测试页 XY 矩阵的轴值删除按钮按下时向下跳动（#598）**

### 升级提示

- 本版没有必须执行的数据迁移；照常停止运行中的任务、关闭 Studio，并在更新前备份 `studio_data/`。
- 如果训练集里有不想参与训练的未打标图片，请在开训前把它们移出训练集，规则见 [Caption 格式说明](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/caption-format.md)。
- 28 层底模（Anima 1.0 等）上训练的 LoRA 与 40 层的 Anima-2.9B 不互通，反之亦然。旧 LoRA 没有层数记录时按权重键名推断，可能显示黄色提醒。
