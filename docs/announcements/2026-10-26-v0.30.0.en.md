New model family: MOSS-Image · Muon and Riemannion optimizers · step checkpoints now resume exactly where training left off

### Added

- **New model family: MOSS-Image (#606, #607, #608, #609, #610, #611, #613, #616, #621, #627, #628)**
  You can now pick MOSS-Image as the model family on the Train page (a 5B single-stream DiT with a Qwen3.5-9B text encoder and the FLUX.2 VAE). LoRA training, in-training previews, single-image and XY generation on the Generate page, prior generation, and post-training evaluation all work with it. The Train tab in Settings has a new MOSS-Image section for downloading the Base / SFT main model (bf16 / int8), the text encoder (int8 / bf16), and the VAE.
  - Comfy-Org's int8 ConvRot quantized bases work directly for training and generation. With an int8 base, only LoRA / LoKr / LoHa are supported (no DoRA), and gradient checkpointing must be on.
  - Generation on an int8 base follows ComfyUI's math, so results stay closer to ComfyUI with the same settings. LoRAs you train load directly in ComfyUI.
  - The Generate page adds Skip Layer Guidance settings (skipped layers, start, end). By default it skips layer 22 for the whole run, matching the official setup.
  - Supports block swap (42 layers), VRAM policies, the flash-attn / xformers attention backends, and NaViT packed training (text tokens count toward the packing budget).
- **Muon optimizer (#623)**
  Muon is now an optimizer option on the Train page, and you can keep your AdamW learning rate. Advanced mode exposes momentum, orthogonalization steps, and the learning-rate scaling mode. See the [optimizer guide](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/optimizers.md).
- **Riemann LoRA adapter and Riemannion optimizer (#624)**
  The two only work together: choosing Riemann LoRA locks the optimizer to Riemannion, and Riemannion is unavailable with other adapters. Saved files are regular LoRAs that load directly on the Generate page and in ComfyUI, and you can continue training from an existing regular LoRA.
  - Riemann LoRA doesn't use alpha, DoRA, rs-LoRA, dropout, or per-layer rank, so those fields are hidden when it's selected.

### Changed

- **Resuming from a mid-epoch step checkpoint now skips the part of the epoch already trained (#625)**
  Training used to restart from the beginning of that epoch, so some images were trained twice, and with a step limit the images at the end of an epoch could be skipped entirely. A resumed run now follows the same loss curve as one that was never interrupted.
  - Checkpoints saved by older versions don't record progress within the epoch, so they still resume from the start of the epoch.
  - With InfoNoise on, training with the same seed follows a slightly different trajectory than in older versions.
- **Anima's er_sde sampler now computes the same way as ComfyUI (#616)**
  Images from the same seed may differ very slightly.

### Improved

- **Anima and Krea 2 now explain int8 quantized bases and text encoders up front (#605)**
  These families don't support the int8 quantized weights popular in the ComfyUI community (such as `*_int8_convrot`). Instead of an unclear error once training or generation starts, loading now tells you to use the bf16 or fp8 version of the same model. Settings and base-model dropdowns mark these files as unavailable and disable them.
- **Settings help text moved into ⓘ buttons (#622)**
  The gray help paragraphs on each tab now live in the ⓘ next to the relevant heading or field, and models that aren't downloaded show “Not downloaded · ~size.” VAE, text encoder, and tokenizer cards now match the main model cards.

### Fixed

- **Generating with block swap could still move swapped-out layers onto the GPU in some cases (#614, #615)**
  This happened when Krea 2 freed VRAM for the text encoder, and when Anima freed VRAM around VAE decoding. Block swap stopped helping, and smaller GPUs could run out of memory. With block swap on, Anima now also frees the resident layers before VAE decoding, so it falls back to tiled decoding less often.
- **ⓘ help panels were cut off in narrow sidebars (#612)**
  Pressing Esc inside a dialog or drawer now closes only the ⓘ panel instead of the whole dialog.
- **Finishing “Crop current image” cleared unsubmitted crop boxes on other images (#618)**
- **The LLM preset editor jumped to the top or bottom after editing a prompt message (#620)**

### Upgrade notes

- No data migration is required. As usual, stop running tasks, close Studio, and back up `studio_data/` before updating.
- The minimum transformers version is now 5.3 (required by MOSS-Image's text encoder), which also upgrades dependencies such as huggingface_hub and tokenizers. Updating through Studio's built-in updater installs them automatically. If you update manually with `git pull`, run `pip install -r requirements.txt` again in the venv.
