# 本地主题词库

入口：设置的标签词典区域，或单图／批量「整理提示词」旁的「主题词库」。链接在新标签页打开，避免离开未保存的编辑页。地址为 `/tools/tag-topics`。

## 查询和整理

左侧按大类、主题族和具体主题浏览；右侧支持英文、中文、来源和归类状态筛选，以淡彩卡片显示，每页 12 条。卡片根据可用宽度排列为三列、两列或一列，同一标签的颜色保持一致。未明确归类的候选来自本地已安装的翻译词典，不会自动变成正式映射。没有下载翻译词典时，内置主题词库仍可独立使用，中文主题名称仍可检索。

点击卡片只选中词条，下方详情条显示归属路径和匹配说明；筛选或翻页使词条离开当前结果时清除选择。词条详情展示生效来源、关系、同主题词和相关主题。相关主题只是浏览导航，不意味着同一排序组。下方「整理预览」左侧输入原始提示词，右侧用彩色标签显示整理结果，逐词原因可展开查看；原始大小写和重复词保留，不修改图片标签。

`breast`、`breasts`、`chest` 归为胸部主题，但 `chest tattoo`、`chest harness`、`hand on chest` 分别属于纹身、束带、手部动作。关系为主题关联，不是同义词替换。

## 修正与保存

点击卡片的编辑图标或详情条「编辑归类」打开右侧抽屉，可调整所属主题、关系、基础词优先以及来源说明；勾选「排除自动归类」可让标签保持原位。作品／角色身份保护优先于用户覆盖。新增词条和新建／编辑自定义主题也使用抽屉，卡片布局不随抽屉打开而改变。保存后抽屉保持打开；保存失败保留输入，关闭未保存表单时会先确认是否放弃，关闭后键盘焦点返回入口。

「保存修正」立即保存全局词库，影响下次整理；不会自动修改已经打开的图片。训练标签仍然需要在标签编辑页另行保存。「恢复内置」删除该词的用户覆盖；不存在内置归属时恢复为组合规则、保守规则或未知词。

「新建主题」使用 `user:` 前缀的 ID，可独立成组，也可选择同大类的既有排序聚合组。词形归一化仅用于查询匹配，原始大小写、下划线、重复标签均保留。

## 导入、导出和更新

导出只包含用户自建主题与标签覆盖。导入先预览新增项、冲突及双方内容，默认保留本地冲突项；勾选覆盖后再确认导入。导入整体校验和事务提交，失败不留下部分修改。

数据库位于当前配置的数据目录 `tag_dictionary/semantic.sqlite`。内置数据更新按版本替换独立内置表，不覆盖用户表；没有模型下载或在线推理。词库请求失败时保留上次快照；首次加载失败时明确提示并退回原有整理规则。

首版内置 136 个具体主题、939 条精确映射及 15 条受约束组合规则。词条是编辑用主题分类，不保证每条都是某个图库的官方标准标签；未明确归类候选须人工确认后补充。
