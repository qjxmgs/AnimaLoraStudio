# 自动头部遮罩

本地 v0.27 定制版保留两个入口：页头“自动遮罩”是官方快捷矩形流程；
“训练遮罩”模式右侧的审阅面板是本地精细轮廓流程。只有后者提供逐脸确认、
安全替换和独立撤销。下文的精细轮廓与旧提案操作均指右侧审阅面板。

## 仅脸部 · 精细轮廓

新版默认选择“仅脸部 · 精细轮廓”。头部检测框只给分割模型提供输入，最终橙色
预览是脸部像素遮罩。目标是可见脸部及完整五官，尽量保留头发、脖子、肩膀和
遮挡物。特殊画风、侧脸、小脸须逐图检查。漏检/分割失败不会退回矩形或椭圆，
可用“未检测到”筛选并手工修补。

首次点击“下载并准备脸部分割模型”，或在设置的头部模型区准备。权重约 5.74 MiB，
但独立转换环境还需下载数百 MB 的依赖。日志可查看进度/失败原因，失败可重试。
主训练环境不安装 Ultralytics/OpenCV，准备成功后走 ONNX 推理。所有权重、
转换产物和转换环境均只保存在本机，不上传、不进入 Git。

默认脸部置信度 0.25、NMS IoU 0.7、分割阈值 0.5、不外扩、不羽化。
可设置 1–3 像素向内羽化，它不会扩大忽略区。检查轮廓并取消误检后再“应用所选”。
应用后仍可通过手工画笔/橡皮修改 `.mask`。

### 缩小已保存的方形遮罩

“应用所选”只取并集，不能恢复旧矩形里多遮住的肩膀。请用“替换旧自动遮罩”：
选择旧应用记录 → 选择新脸部区域 → 预览差异 → 确认。黑色为忽略区、白色为
学习区，同时显示恢复学习/新增忽略的像素数。未选图片或没有选中脸部的图片
保持原遮罩，不会被自动清空。

仅当旧记录、原图、当前遮罩和快照能验证时才允许替换。存在后续手工修改、
快照损坏或来源不明时会拒绝并说明原因；请手工修补，不要删除所有 `.mask`。
更早的手工内容保留。撤销替换回到替换前状态（包括旧矩形）；之后又做了手工
修改时拒绝自动撤销。所有自动操作前必须保存笔画。

训练仍需开启 masked loss，遵守 Leap/NaViT Packing 互斥规则。空间遮罩不等于
删除身份标签，caption 中的人物名、发色、眼睛等不会自动删除。

## 头部矩形（旧模式）

自动头部遮罩适合训练服装、姿势、画风等 LoRA 时忽略卡通人物的脸、头发、耳朵和头饰。它只生成 `.mask`，不会修改原图。

## 使用步骤

1. 进入项目版本的“预处理 → 涂抹 → 遮罩”。首次使用时点击“下载头部检测模型”；权重约 42.5 MiB，下载后会自动校验。
2. 保存页面上所有未保存的手工笔画。存在未保存笔画时，批量检测会被阻止。
3. 点击“检测全部”，或只对当前图片点“检测当前”。默认参数通常适合二次元插画：置信度 0.413、NMS IoU 0.7、外扩 10%、羽化 3%。
4. 检测完成后检查橙色框。每个框默认选中；可逐个取消，也可对当前图全选或全不选。“未检测到头部”筛选可快速定位漏检图。
5. 点击“应用所选”。自动遮罩会与已有手工遮罩取像素最小值，因此不会覆盖或恢复手工忽略区域。
6. 前往训练页。若存在 `.mask` 而 `masked_loss` 关闭，使用“一键启用”。Leap 和 NaViT Packing 与 masked loss 仍互斥，需先关闭冲突选项。

## 参数说明

- **置信度**：越高越少误检，也更容易漏掉小头部。建议先使用 0.413；误检多可调至 0.5–0.6。
- **NMS IoU**：去除重叠框的阈值。默认 0.7 能保留靠得很近的多个人物。
- **外扩比例**：按检测框宽高向四周扩展。默认 10%，用于覆盖发梢、兽耳和头饰边缘。
- **羽化比例**：在扩展区域外缘建立从 0 到 255 的过渡。默认 3%，降低硬边界对训练的影响。

## 安全与撤销

- 检测只写提案，不写原图或遮罩。应用时先校验整批源图并生成临时文件，再逐个原子替换；任何准备阶段失败都不会写入部分结果。
- 图片尺寸、文件大小或修改时间在检测后变化时，提案会标为过期并拒绝应用，请重新检测。
- “撤销本次自动遮罩”恢复应用前快照。若应用后又手工修改过任一相关 `.mask`，系统会拒绝撤销，避免覆盖新修改。
- v1 不清理 caption。人物名、发色、眼睛等身份标签仍会参与文本条件训练；如需忽略，请在打标页手工删除。

模型来自 `deepghs/anime_head_detection`，固定 revision 和校验值见 [ADR 0017](../adr/0017-proposal-based-auto-head-mask.md)。权重不随本项目分发，许可信息见根目录 `THIRD_PARTY_NOTICES.md`。

## v0.27 官方快捷矩形流程

自动头部遮罩适合训练服装、姿势、画风等 LoRA 时忽略卡通人物的脸、头发、耳朵和头饰。它只添加尚未保存的 `.mask` 修改，不会修改原图或 caption。

## 配置识别模型

进入“设置 → 预处理 → 头部检测器”。头部检测器与放大器使用相同的模型来源管理方式：

- 可选择 HuggingFace 或 ModelScope 作为下载源。
- 用单选项设置全局默认检测器。
- 可使用固定的内置检测器，也可通过仓库和 `.onnx` 文件名添加下载，或登记现有的绝对 `.onnx` 路径。
- 下载模型由 Studio 管理并放在检测器模型目录；登记的本地文件原地使用，不会复制或删除。
- 移除或删除当前选中的自定义检测器后，会安全回退到内置检测器。

内置权重固定 revision、大小和 SHA-256。自定义检测器必须符合当前 YOLO ONNX 输入输出布局；模型缺失或不兼容时任务会安全失败，不修改任何图片或遮罩。

## 使用步骤

1. 进入项目版本的“预处理 → 涂抹”。点击页头“自动遮罩”（在“保存全部”左侧）。
2. 选择已安装的“识别模型”，再选择“全部图片”或“当前图片”，配置置信度、扩展比例和羽化比例。没有兼容模型时，弹窗会提示前往“设置 → 预处理”；弹窗内不提供模型下载或文件管理。
3. 点击“开始”。NMS IoU 在内部使用既定默认值 0.7。成功加入队列后弹窗关闭，后台任务由当前页面继续跟踪。
4. 检测完成后，每个成功且未过期的区域会直接加入对应图片的遮罩层，成为未保存修改。编辑器自动切换到“训练遮罩”和“画笔”，可立即用画笔或橡皮修正。失败、跳过、过期以及成功但未检测到头部的图片保持干净。
5. 每张受影响图片只增加一个分组历史操作，无论检测到几个头部。Ctrl+Z 一次撤销该图片的整组自动遮罩，重做可恢复；后续手工遮罩笔画继续使用同一历史。
6. 使用现有“保存当前”或“保存全部”持久化遮罩。在保存之前，Filmstrip 的待保存状态会包含自动遮罩修改；存在未保存修改时不能启动另一轮自动遮罩。
7. 前往训练页。需要时启用 masked loss。Leap 和 NaViT Packing 与 masked loss 仍互斥，需先关闭冲突选项。

当前界面没有提案审核面板、可选择的检测框覆盖层、“应用”按钮或独立的自动遮罩撤销按钮。提案数据仅作为后台结果传到现有遮罩编辑器。

## 参数说明

- **置信度**：越高越少误检，也更容易漏掉小头部。默认 0.413。
- **扩展比例**：按检测框宽高向四周扩展。默认 0.10（10%）。
- **羽化比例**：在扩展矩形外建立精确的过渡。默认 0.03（3%）。

数值范围：置信度为 0.01–0.99，扩展为 0–1，羽化为 0–0.5。空值或越界值会在字段旁提示。NMS IoU 固定使用既定默认值 0.7，不在弹窗显示。

## 安全性

- 检测和结果读取不会持久化图片或遮罩；“保存当前”和“保存全部”是唯一持久化边界。
- 结果接口会检查源图片身份。图片尺寸、文件大小或修改时间变化而被标记为过期的结果不会加入编辑历史。
- 项目、版本和任务身份会守护异步响应，迟到响应不能修改另一个工作区。
- 旧版提案/应用/撤销接口继续供旧客户端兼容，但当前界面不会调用应用或撤销接口。
- 本功能不清理 caption。人物名、发色、眼睛等身份标签仍会参与文本条件训练；如需忽略，请在打标页手工删除。

内置模型来自 `deepghs/anime_head_detection`，固定 revision 和校验值见 [ADR 0018](../adr/0018-proposal-based-auto-head-mask.md)。许可信息见根目录 `THIRD_PARTY_NOTICES.md`。
