# Appearance and anime themes

Open **Settings → Appearance → Theme style** and select Sakura Encore, Sky Club,
Star Terminal, or Classic. Each preset supports light and dark modes. The sidebar
toggle stays synchronized with Settings, and density is independent of the preset.

Sky Club is the default when no preset has been selected. Existing light/dark and
density choices are retained. Select Classic to restore the original warm studio.
Preferences persist in this browser; when storage is blocked they still work for
the current session. Theme cards support arrow keys, Home, End, Space and Enter.

Turn off **Decorative motion** to disable the welcome atmosphere and decorative
control feedback. System reduced-motion preferences also disable these effects.
Functional task progress remains available. Editors have no ambient animation,
and media previews retain neutral backgrounds without artwork or color filters.

The large welcome mascot collapses in narrow workspaces. Switching appearance
does not save/discard drafts or start, stop, or restart tasks.
