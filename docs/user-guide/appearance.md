# 外观与二次元主题

进入 **设置 → 外观 → 主题风格**，点击预览卡即可立即换肤：

| 主题 | 视觉风格 |
| --- | --- |
| 樱糖应援 | 莓粉、蝴蝶结、星光与偶像后台 |
| 晴空社团 | 蓝白、社团手册与窗边创作室 |
| 星轨终端 | 青蓝、切角面板与轨道观测站 |
| 经典 | 原来的暖米白／深棕工作室 |

每套主题都有日间和夜间版本。侧栏明暗按钮与设置中的选择实时同步，
切换主题不会改变界面密度。首次使用主题预设时采用晴空社团，并沿用之前的明暗选择。

主题、明暗、密度与装饰动效保存在当前浏览器，刷新后恢复。浏览器禁用存储时，
本次会话仍可换肤。主题卡支持方向键、Home、End、空格和 Enter。

关闭 **装饰动效** 可停止首页氛围动画与主题控件的装饰反馈；系统要求减少
动态效果时也会停用。任务进度等必要状态仍正常显示。
工作区不播放环境循环动画，图片预览不会受到角色、背景或颜色滤镜覆盖。

窄窗口会收起首页的大立绘，侧栏头像和主题配色继续保留。
主题切换不会保存／丢弃编辑草稿，也不会启动、取消或重启任务。
