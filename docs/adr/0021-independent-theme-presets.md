# 0021 — 独立保存主题风格与明暗模式

**状态**：Accepted
**日期**：2026-09-19
**决策者**：维护者确认的二次元主题替换方案

## 背景

原界面仅保存 `studio.theme=light|dark`。新增樱糖应援、晴空社团、星轨终端，
每套包含日夜外观，并保留经典主题。换肤不能重建编辑器或影响运行任务。

## 候选方案

- 将六种外观加入原 `Theme` 枚举：会混淆风格和明暗，破坏现有侧栏切换语义。
- 为每套主题复制页面：状态及样式容易分叉，换肤可能丢失草稿。
- 独立预设和共享 CSS 变量：复用原组件与明暗 API，集中处理视觉差异。

## 决策

采用独立预设。新增 `studio.themePreset`（classic/sakura/sky/star）和
`studio.themeEffects`，保留 `studio.theme` 与 `studio.density`。
无预设记录默认 sky，保留明暗与密度；未知预设回退 classic。
偏好不进入服务端配置、项目 bundle 或任务参数。存储不可用时保留会话内状态。

通过 `useSyncExternalStore` 同步设置面板、侧栏及装饰组件；在首次挂载前
设置根节点 CSS 属性。跨标签页 storage 事件同步外观，不改变路由树的 key。
大型素材随前端静态文件发布，仅在首页加载当前预设对应的立绘和日夜场景。

## 理由与后果

全站共用控件保留行为与语义，六套视觉不需要复制业务代码。图片预览使用
中性背景，装饰不拦截输入。旧用户默认得到晴空外观，可在外观设置中切回经典。
新增静态图片增大发布包，但不引入在线字体、渲染库或额外 GPU 动画运行时。
