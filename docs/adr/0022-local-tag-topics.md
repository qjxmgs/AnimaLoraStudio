# 0022 — 独立本地提示词主题词库

状态：Accepted · 2026-11-09

## 决策

使用 `STUDIO_DATA/tag_dictionary/semantic.sqlite` 保存编辑用语义词库。翻译词典继续负责英文／中文和身份分类，不以同译文推断同义。内置主题与映射从 `studio/data/tag_topics.json` 事务导入，用户主题和覆盖使用独立表。结构版本、种子版本和有效修订号分开记录。

精确用户覆盖、内置例外、受约束组合规则和保守回退依次处理；作品／角色身份保护始终优先。JSON 同时保存回退规则与组合规则正反例；Python 查询解释与 TypeScript 整理读取同一套规则数据，测试锁定语义。

全局 API 位于 `/api/tag-topics`：snapshot、topics、entries、explain、export、import。导入默认为预览，显式 apply 才修改，默认保留本地冲突。所有词条查询均在本机完成，不引入依赖或后台任务。

前端保存最后成功快照，窗口聚焦和同源 storage 修订通知触发刷新，失败保留快照；没有快照时使用既有规则并提示。每次整理同步使用当前快照，不自动重排打开的草稿。

## 页面任务说明

遵循 DESIGN.md 的 document page 结构与 PageHeader、Button、FormControl 原语。主滚动由 AppShell 负责；主题树是有界辅助导航，查询和维护面板属于词库工作区，不替换标签编辑页原操作。参考 Settings 的全局配置作用域和 Presets 的维护语义；导入需要先预览冲突，采用页内预览以便比较双方完整文本。

主题词库链接打开新标签页，以保留正在编辑的训练标签；编辑页通过聚焦刷新读取修正。这里保存的是立即生效的全局分类配置，不是训练 caption 的 SaveBar 生命周期。

## 后果

词库独立迁移和备份，项目数据库不变。查询为有限本地数据构建候选目录并分页返回；不依赖中文分词。未来添加内置数据必须递增种子版本并验证用户主题引用，升级失败保留原数据。没有任意用户正则执行、自动近义词推断或模型训练变更。
